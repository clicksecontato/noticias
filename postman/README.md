# Postman – Notícias IA (todas as rotas)

1. Abra o Postman.
2. **Import** → escolha o arquivo `Noticias-IA-API.postman_collection.json`.
3. A collection **Notícias IA - Todas as rotas** será adicionada.
4. Defina as variáveis `base_url` e `admin_token` (mesmo valor de `ADMIN_INGEST_TOKEN`).

Rotas de exemplo usam fontes/assuntos de IA (`tecnoblog`, `canaltech-ia`, `chatgpt`).
